# Project Overview

 This Project is part of the **NEBULA xplorers** hackathon organized by [FDND](https://fdnd.nl/) and [CMD](https://cmd-amsterdam.nl/) web minors. 

We worked on transforming the infographic of Nabula explorers 

### Infographic: ![Nebula Xplorers Infographic](/src/assets/NEBULA%20-%20infographic.png)

into an interactive web experience. The project is built using React and Vite.

# [Live demo link](https://nebula-hackathon.netlify.app/)

## Tech Stack

- React: For building the user interface and managing state.
- Vite: For fast development and build tooling.
- CSS: For styling the components and layout.
- GASP: For animations and interactive effects.
- JavaScript: For adding interactivity and handling user events.


### Getting Started

To run the project locally, follow these steps:
1. Clone the repository:
   ```npm
   git clone <https://github.com/Ravirkt/hackaton.git>
   ```
2. Navigate to the project directory:
   ```npm  
    cd HACKATON
    ```
3. Install dependencies:
   ```
   npm install
   ```  
4. Start the development server:
   ```npm
    npm run dev
    ```

### Features

- Interactive experience : Users can click on different company names  from the nav bar of the page to explore more information about each one.
- Animations: Smooth animations enhance the user experience and make the experience more engaging.
- Responsive Design: The web experience is optimized for various screen sizes, ensuring accessibility on both desktop and mobile devices.
- User-Friendly Interface: The interface is designed to be intuitive and easy to navigate, allowing users to quickly find the information they are interested in.
- Accessibility: The project follows accessibility best practices to ensure that it can be used by a wide range of users, including those with disabilities.
